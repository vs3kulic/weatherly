# Weatherly
This is a small CLI-Tool that fetches the weather data for a city and provides tips on the appropriate outfit. It also prints a cheerful quote of the day.

Bonus: A quote for a day.

## Features
- Dynamic city geo-location
- Real-time weather data
- Outdoor clothing tips
- Quotes to brighten the day!

## Integrations
- Meteo API
- Nominatim API (tbd)
